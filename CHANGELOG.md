# Changelog

All notable changes to this project are documented here.

## [1.0.0] - 2026-03-16

### Added

- Recipe browsing: categories, search, country filter, recipe pages with ingredients and video
- Favorites and light/dark theme persisted in localStorage
- PWA: install prompt, offline support, service worker caching, update reload prompt
- MIT license and TheMealDB attribution

### Changed

- Refactored data fetching with QueryBoundary and centralized query options
- Mobile browser theme-color syncs with navigation bar in light/dark mode
